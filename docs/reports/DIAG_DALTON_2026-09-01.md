# ב. שני החוסמים

## ‏1. ‏`daytype_playbook` — `FAMIR` ו-`VEGAS` הם `SKIP` בכל שמונת סוגי-הימים

```
FAMIR (REV)  Normal SKIP · Variation SKIP · Trend_Normal SKIP · Trend_DD SKIP
             Neutral_Center SKIP · Neutral_Extreme SKIP · Nontrend SKIP · Nonconviction SKIP
VEGAS (REV)  זהה — SKIP בכל שמונה
```

**שורה שכולה SKIP אינה פלייבוק — היא כיבוי.** והיא **סותרת את הקונפיג של עצמה**:

```yaml
daytype_style.Normal:
  fade_edges: True
  bias: 'VAL→LONG · VAH→SHORT (fade to value)'
  note: 'fade VA edges: SHORT only near VAH, LONG only near VAL'
```

**זה בדיוק הכלל של מייקל, כתוב בקונפיג — ודפוס-דהייה מקבל SKIP ביום-דהייה.**
להשוואה, `DBDT` (גם REV) מקבל `Normal: FULL`. ⇒ ‏`FAMIR`/`VEGAS` הן **שורות מתות**.

## ‏2. ‏`awaiting_release` דורש 2 שפלים-עולים — ולכן אי-אפשר לקנות שפל

הנימוק שהמערכת כותבת: *"waiting for the zone release — structure not turning
(1/2 higher lows)"*. **בשפל-היום, עד שיש שני שפלים-עולים, השפל כבר 5+ נק' מאחוריך.**
זה מנגנון-"מאוחר-מדי" זהה לזה של הפתיחה, בצד הלונג.

**‏🔴 ולא להסיק מכאן שהשער מיותר** — 281 מ-292 חסימותיו אתמול היו על `S2_DELTA_DBL_LONG`,

# ד. השורש המאחד — ולמה הוא מייצר את שתי התופעות

```

סטופ מבני מתחת לשפל-היום:   11 נק'
SIZE_CAP_CUT cap בפועל:      3.1 · 3.3 · 3.9 · 4.0 נק'   (~1.2×ATR14)
```

**התקרה קטנה מהסטופ שעסקת-דלתון דורשת.** לכן:
- כניסה **בקצה** ⇒ סטופ מבני רחב ⇒ נחתך לרצפת-2 או לסטופ-בתוך-הרעש
- כניסה **באמצע-התנועה** ⇒ הסטופ המבני כבר צר ⇒ עוברת את התקרה

⇒ **התקרה בוררת כניסות מאוחרות.** אין כאן באג — יש כאן פרמטר שמייצר בדיוק את
ההתנהגות שמייקל מתלונן עליה. **וזו הסיבה שאין להתחיל מ"תבנית חדשה":** תבנית חדשה
שתזהה את השפל תיחתך באותה תקרה בדיוק.
