## עקרון

git משכפל את הקוד; **חמישה משטחים חיים מחוץ ל-git** וחייבים טיפול ידני-פעם-אחת:
`.env` · בינארי-ה-DLL (בילד מקומי + Remote Build בסיירה) · LaunchAgents ·
תצורת-סיירה (צ'ארטים, סטאדי, Input-4 נתיב-ייצוא) · Postgres מקומי (מתחיל ריק —
הנתונים נבנים מהפיד; אין תלות בהיסטוריה של מק-1).

## שלב 0 — פיזי (מייקל, ~10 דק')

1. להדליק את ה-iMac (T-04: ‏100% packet loss = כבוי/ישן מאז ~17.08).
2. חשמל קבוע + `sudo pmset -a sleep 0 disksleep 0 displaysleep 10 autorestart 1`
   ו-`sudo pmset repeat cancel` — זה מה שהופך אותו ל-24/7 (וזה מה שנכשל במק-1, T-42).
3. סיירה ל-Login Items (מחלקת T-43 — ריבוט חייב להחזיר את סיירה לבד).

## שלב 1 — סנכרון-קוד (cc-imac, ~15 דק')

```
cd ~/Downloads/mems26_web_git && git pull
python3 scripts/flag_guard.py          # אימות-סנכרון (פסיקת 08-13)
```
ואז המשטחים שמחוץ ל-git:
- `.env`: להעתיק מ-snapshot של מק-1 (`~/mems26_snapshots/<אחרון>/env`) ולשנות
  פר-מכונה: `MACHINE_TAG=mac2` · `RENDER_MOBILE_URL=https://mems26-phone-mac2.onrender.com` ·
  נתיבים אם שונים. **לא** לשנות דגלי-מסחר — זהות מלאה (עקרון-הזהות).
- DLL: `./scripts/build_monolithic_cpp.sh --deploy` → Remote Build בסיירה → reload study →
  לוודא Input-4 = `/Users/<user>/SierraChart_Data/v9_export/`.
- LaunchAgents: להתקין מהריפו (backend · bridge · export-promoter · mobile_relay ·
  startup_check) — `KeepAlive` מותנה כמו במק-1, `CLOUD_URL=http://localhost:8000` קשיח.
- Postgres: `createdb mems26` + מיגרציות; מתחיל ריק.

   סיגנל + מרג'ין כפול שאין. ההמלצה = הפסיקה המקורית שלך (07-11): **מק-2 = הסוחר
