## חוקי-הזהב (על כל שלב)
1. **פער אחד בכל פעם.** לא מתחילים את הבא עד ש-cowork סימן PASS על הנוכחי.
2. **דגל חדש = default OFF בקוד.** הדלקה = פסיקת-מייקל + `.env` + RULED + ריסטארט + `flag_guard`.
3. **שער-סיכון → אימות-סים** (`sim_matrix` + E2E) לפני `.env` ON.
4. **כל סגירה = טסטים אנטי-טאוטולוגיים + פקודה+פלט-גולמי ב-`LIVE_CHANNEL`** (לא הצהרה).
5. **דגל-OFF חייב להיות byte-identical** להתנהגות הישנה (טסט-הוכחה).
6. **אין op=EXIT · אין סינתזה** (`"Normal"` אסור כנסיגה) · **אין קריאת `.env`** מהסנדבוקס (flag_guard בלבד).
