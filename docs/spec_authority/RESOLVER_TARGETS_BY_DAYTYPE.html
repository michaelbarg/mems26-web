MEMS26 · יעדי-מימוש מבניים לפי סוג-יום ותבנית

הרזולבר קובע יעדים לפי סוג-היום והמבנה, לא לפי זהות-התבנית. התבנית קובעת רק כיוון + משפחה (המשך/היפוך). טיוטה לעריכה — 2026-07-01.

חוקי-הבסיס (זהים לכל התבניות):
• C1 / T1 = ה-swing המבני הראשון בכיוון (Williams K=2, close-confirm) · רצפה 0.5×ATR₅ₘ≈3.5 · קאפ min(2×ATR₅ₘ, 0.30×dATR)≈14.
• C2 = מבנה קרוב (POC · IB-center · swing-ביניים) — בנקאי בטוח, קרוב יותר מקצה-הערך.
• C3 = קצה-הערך (VAH long / VAL short) או extension — הרנר, עם room + trail.
• קאפ קשיח: יעד מעל הקאפ → נצמד למבנה-הקרוב. runner-cap min(1.5×dATR, 3×IBw).
• היפוכים: מבנה-נגדי / mean-reversion → POC, לא measured-move-לפי-גובה. ATR₅ₘ שלנו = 7.07 (אומת).
