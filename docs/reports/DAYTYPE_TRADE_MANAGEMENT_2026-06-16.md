## כלל-העל למימוש
- **יום מגמתי → היעד הוא תנועה** (R-multiples / trail). אל תמכור לתוך החוזק.
- **יום רוטציוני → היעד הוא מיקום** (POC / VAH / VAL / קצה-IB). הקרוב מנצח.
- לכן T2 קבוע של 2R נכשל ביום Variation — קצה-ה-IB קרוב יותר מ-2R.

## סולם הזזת-הסטופ (אחיד לכל התבניות)
- **סטופ-1**: עוגן מבני + 3 טיקים, תקרה **12–20 נק'** פר-תבנית. מעבר לתקרה → CONT: SIZE-DOWN · REV: SKIP.
- **אחרי T1**: לעוגן-המשנה המבני (בר-האות / b3 / כתף / קצה-דגל) — **לא BE-בדיוק** (מלכודת stop-hunt, D-002).
- **אחרי T2**: BE + 0.3–0.5R, ואז **trail דו-בר** (נמוך/גבוה של 2 הברים האחרונים).
- **ראנר ביום Trend**: chandelier 2.5–3×ATR או CCI-cross — עד סוף-סשן.
- **פיקוח CVD בכל שלב**: divergence נגד-הפוזיציה אחרי T1 → הידוק BE מיידי · CVD מתחזק → להרחיב trail מדרגה.

## דוגמאות
1. **Trend_Normal (יום עולה):** ZLR LONG על דחיית CCI חזרה ל-+50 → T1 ב-0.75R (נעילת חוזה) → **trail את השאר במעלה המדרגות** (דו-בר / chandelier), T2 בשיא-הסווינג הקודם, T3 רץ עד הסגירה. *(אתמול #97/#98 ZLR LONG +289/+218 ב-TIME_STOP = בדיוק זה — ראנרים שניתנו לרוץ.)*
2. **Normal:** מחיר ב-**VAH → שורט**, T1 ב-**POC** (מהיר), T2 ב-VAL (קצה-IB נגדי), סטופ מעל VAH. *(הדוגמה שלך.)*
3. **Variation (הרחבה למעלה):** קנייה **עם ההרחבה**, T1 = ½×ההרחבה, T2 = 1×IB, trail T3, סטופ בקצה-ה-IB שנפרץ.
4. **Neutral_Center:** fade VAH → שורט ל-POC/VWAP **ולצאת מיד** (אין ראנר).
