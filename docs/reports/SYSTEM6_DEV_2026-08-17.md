## Invariant 13 — `target_divergence` limitations

The `sierra_targets` source is `get_last_place_command()` — an **in-memory** dict populated
when a PLACE command is written. It does NOT survive backend restarts. Trades opened before
the current session will have `sierra_targets=None` → invariant 13 stays silent (honest skip).

For persistent sierra-target tracking:
- **Option A:** Write the PLACE targets to `v9_trade_management_log` with action='PLACE_TARGETS'
  at command time → readable across restarts.
- **Option B:** Read the command queue JSON files from `~/SierraChart_Data/v9_export/command_queue/`.
- **Option C (B3):** DLL-side tracking — Sierra knows its own target prices; the DLL could
  export them in the same bridge path as position/fill data.

All three are B3 territory. The current wiring provides evidence for same-session trades.
