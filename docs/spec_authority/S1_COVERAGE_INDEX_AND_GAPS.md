## 0 · ביקורת עצמית — למה זה לא בוצע נכון מלכתחילה (בעיה רצינית)

אתה צודק, וזו כשלשל-תהליך, לא רק באג. בכנות, מה שעשיתי לא בסדר:

1. **לא בניתי אינדקס-כיסוי לפני שכתבתי קוד.** קראתי חלקים מהאפיון והתחלתי לקודד מסווג — התייחסתי לאפיון כאל *השראה* ולא כאל *צ'ק-ליסט מחייב*. התוצאה: יישמתי תת-קבוצה וניחשתי את השאר.
2. **השמטתי ווליום לחלוטין.** האות הכי חשוב ל-Nontrend, שמופיע באפיון שלך שוב ושוב (VA-width↔volume, "ווליום נמוך לנר") — והיה בידיי בתוך הברים — נזרק. הוספתי אותו רק אחרי ש**אתה** תפסת את 06-19. למסווג סוגי-ימים שבו ווליום הוא דיסקרימינטור ראשי, זה כשל יסודי.
3. **ניחשתי ספים** במקום להשתמש בבנדים המדויקים שלך (Variation 1.3–2.5 במקום 1.3–2.0 שלך; Nontrend rib≤1.5 במקום ≤1.15) — והניחושים האלה הם בדיוק מה שגרם לשגיאות (06-19→Variation, החפיפות).
4. **נתתי ל-FORMING להיות מזבלה שקטה** ל"אמצע" — בדיוק "פער הכיול" — במקום להכיר שכל יום חייב להיפתר, ושהקלטים שצריך כדי לפתור אותו (PDH/PDL, opening-range, ווליום) פשוט חסרים.
5. **לא סימנתי קלטים חסרים/מזוהמים.** עקפתי אותם בשקט (פרצנטיל-IB מזוהם, PDH/PDL לא מוזן, opening-range/ON-H-L/VIX נעדרים) במקום לומר "הקלטים האלה חסרים — הסיווג לא יכול להיות נכון בלעדיהם".
6. **שורש:** העדפתי "התקדמות נראית-לעין" (מסווג שרץ + UI) על פני "ליישם את האפיון המלא נכון". למערכת-מסחר זו העדפה שגויה — שלמות-נכונות לפני מהירות. התהליך הנכון (שאני עושה עכשיו, באיחור): לאנדקס כל תא באפיון → למפות לקוד → ליישם → לאמת יום-יום.

**מה שמשתנה מעכשיו:** הטבלה הזו (האינדקס) היא החוזה. שום תא לא "מיושם" עד שהוא במבחן יום-יום מול הקריאה שלך.

## 4 · תיקוני-ספים ליישום (לפי ה-✏️ שלך)

1. **Nontrend** rib ≤ **1.15** (לא 1.5) — ה-low-volume override יישאר הדרך ל-06-19 (rib 1.49+ווליום-נמוך), אבל לאשר איתך את הגבול.
2. **Variation** rib **1.3–2.0** (לא 2.5).
3. **Normal** = **IB WIDE מוחלט ≥13 נק׳** (לא פרצנטיל מזוהם) + rib≤1.3 + ווליום רגיל.
4. **Neutral** (שני הסוגים) — להוסיף **rib 1.5–2.5**.
5. **Trend_Normal** — להוסיף **open=extreme** (פתיחה=קצה) כתנאי, ולא להסתמך רק על rib≥2.5.
6. **IB-width** — לעבור לבנדים **מוחלטים** (≤7 / 7–13 / ≥13) עד שהיסטוריית-הפרצנטיל נקייה (היא מזוהמת — ראה I-36).
