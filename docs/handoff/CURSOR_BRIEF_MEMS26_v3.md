## פסיקות-מייקל שעומדות — Cursor אוכף אותן ללא יוצא-מן-הכלל
1. **אפס אחוזי-ביטחון** בשרשרת-ההחלטה. יום הוא סוג או שלא (או "טרם נקבע").
2. **אין הגבלת-שעות. לעולם.**
3. **תבנית מפסידה — מתקנים, לא מבטלים.**
4. **`op=EXIT` שבור** — לא לחווט. יציאות: OCO · MODIFY_STOP · FLATTEN_ACCOUNT.
5. **פסיקה ניתנת פעם אחת ועומדת** — אין לבקש אישור-חוזר.
6. **כלל §D:** אין .env/לייב בלי `week_replay` — דלתא חיובית **וגם** חציון-יום לא-נפגע.

## תפקיד Cursor
1. **לאכוף את הלולאה** diagnose→fix→replay(§D)→verify→gate. **לסרב ל"data-fix"
   שהוא שינוי-סיכון מוסווה** (‏S2_CVD הוא הדוגמה).
2. **תקינות-מדידה קודם-כל** — לתקן את `pnl_reconcile` ואת שכבת-הזמנים **לפני** כל
   החלטת-$.
3. **Backlog מדורג אחד**, חוט אחד בכל פעם. סדר: A-fixes → P3/T-10 → החייאת-תבניות →
   מסווג-בינארי → CONTEXT_ENTRY.
4. **Scorecard-EOD:** כיסוי% (צפון-כוכב: 16%) · fired מול blocked-by-gate · MFE-אחרי-
   חסימה · $ פר-סוג-יום · דריפט IS/OOS · ספרים-מול-ברוקר.
5. **GO/NO-GO טרום-סשן חוסם:** אין פוזיציה-עירומה · reconciler נקי · feed טרי ·
   `flag_guard` PASS · שורת-`[boot] logging OK` עם ה-PID החי. אדום ⇒ לא רץ-חי.
6. **אנטי-טאוטולוגי (חוק-5):** כל fix עם revert→RED + פקודה + פלט-גולמי.
