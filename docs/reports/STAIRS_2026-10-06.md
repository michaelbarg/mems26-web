## 0 · Answer in one paragraph

Under the **locked definition** (stair lows above the **session's** `v9_tpo_sessions.vah_price`), 23 of 66 sessions produced 96 stair-runs. The "money available" long (first stair low → max high in the window) is **+$6,110** — but that number is ≥ 0 by construction (a bar's high is always above its own low), so its 100% win-rate is a tautology, not a result. The **tradeable** long (enter at the close of the bar that completed the stair, exit at the close that breaks the first stair low or at 20:00 IL) is **−$2,726** over the same 96 runs (16% win). The short-at-high with a 2-pt stop is **+$1,385** (36% win; 54 of 96 stopped at −2.00). The day-type filter can only be applied to **12 of 66 sessions** (DECISION vectors start 2026-09-17); among those, stairs-above-session-VAH occurred on **one day only (2026-09-21, 6 runs, all `Trend_Normal`)** — so the filtered and unfiltered tables are identical and the "does the label matter" question **cannot be answered at this N**. **The locked definition does not reproduce yesterday:** on 2026-10-05 the session VAH is 7824.25 and no 17:30–20:00 bar has a low above it; the 18:30 and 19:20 stairs Michael pointed to were above the **IB high (7811.25)** and inside the developing value, not above VAH. ## 2 · Definition as applied (locked, with the three decisions the text left open)

| Item | Applied |
|---|---|
| Window of bars | `ts ≥ 17:30 IL` (IB locked) and `ts < 20:00 IL`, bar open times → bars 17:30 … 19:55 |
| Stair | `low[i] > VAH` and `low[i+1] > VAH` and `low[i+1] > low[i]` (strict) |
| Run | extends while `low[k] > low[k-1]` and `low[k] > VAH`; next run may start only at the bar that broke the previous run (no overlapping runs) |
| VAH | **session** `vah_price` of that `trading_date` (one value for the whole run) |
| Exit window | first bar `j ≥ i+2` with `close < first_low` (that bar excluded from the long's max-high), else all bars to 19:55 inclusive |
| LONG "money available" (Michael's wording) | `max(high over window) − first_low` — **≥ 0 by construction** |
| LONG tradeable (added, labelled) | entry = close of bar `i+1` (first moment the stair is known), exit = close of the breaking bar, or 19:55 close |
| SHORT-at-high | entry = `high[i+1]`, stop = entry + 2.00; checked from bar `i+2`; if any `high ≥ stop` before window end → −2.00, else `entry − min(low over bars i+2..end)`; if no bar after `i+1` inside window → 0.00 |
| Day-type label | latest `DECISION` vector with `ts ≤` close of the first stair bar (`ts[i] + 5 min`) |
| Dollars | points × $5, 1 contract, **no fee/commission in any number below** |
