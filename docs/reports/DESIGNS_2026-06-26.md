**שורש (חשוד, דורש אישור-Sierra תחילה):** מ-13:05 CT והלאה כל בר = עותק byte-identical של (−3h). +3:00 = היסט-IL (UTC+3). חשד מוביל: ה-promoter-sidecar שנכנס **היום** (`scripts/v9_export_promoter.py` + `com.mems26.export_promoter`) — או re-promote של קובץ-בוקר עם timestamp ב-IL-local שמתפרש +3h, או export-אחה"צ קפא וה-promoter "מילא" בעותק-בוקר. **לפני כל תיקון — CC חייב לקבוע היכן נוצר השכפול:** Sierra-export עצמו / ה-promoter / ה-ingest.

**השינוי-המוצע (אחרי האבחון, לפי-הממצא):**

2. **ולידציית-lag (safe):** `lag<0` (בר-עתידי) = בלתי-אפשרי ⇒ `fresh=false` + `logger.warning` (לא debug, §No-silent-failures). מקור: מחשב-ה-freshness ב-`build/pattern-status` + ה-bridge stream.
