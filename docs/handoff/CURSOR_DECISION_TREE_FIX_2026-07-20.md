## המשימה
**A. מקור-אמת אחד (הלב — פסיקת-מייקל #5).** קבע **קובץ-תצורה קנוני יחיד** פר **סוג-יום (×תבנית היכן שצריך)** שמגדיר:
`contracts=4` + scale-out · סטופ (מבני קצה+6T) · progression (אחרי-T1→BE, trail) · כניסה (retest). **בטל את הכפילות**
`targets.yaml`⟂`targets_table.py` (אחד קורא את השני, לא שני מקורות). בטל את השדה-המת `contracts` או הפוך אותו ל-4
מפורש עם חריג-`SIZE_CAP` כלפי-מטה בלבד. הדוק + הקוד + ה-UI קוראים **רק משם**.

**B. תקן את הויזואל** `SYSTEM_DECISION_TREE_VISUAL.html` §⑥ שירנדר מהמקור-היחיד: עמודת-חוזים=4 (לא 3/2/1) · שורת
"אחרי T1 → סטופ ל-BE" · שורת-כניסה "המתן ל-retest של רמת-הטריגר". וגם §④ `entry_not_confirmed` → נסח כ-retest.

**C. פערי-קוד (טרם מיושמים — הצע, אל תבצע בלי פסיקה):** scale-out-של-4 · after-T1→BE · entry-on-retest. לכל
אחד: מצא אם קיים/מחווט (חוק-5, file:line), ואם לא — הצעה עם דגל-OFF + טסט. **מייקל פוסק פר-פריט לפני קוד.**

## אימות (חוק-5)
לכל טענה: פקודה+פלט-גולמי. תיקון-דוק → צילום/דיף. שינוי-מקור-אמת שמשנה התנהגות → דגל-OFF + טסט + פסיקת-מייקל.
ממצאים+הצעות → LIVE_CHANNEL. **cowork מאמת סימטרית.** אל תמציא ערכי-מסחר — מקור-מייקל או שאל.
