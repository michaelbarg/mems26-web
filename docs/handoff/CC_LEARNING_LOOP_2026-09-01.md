## שלב 4 · שיפוט — `scripts/mechanism_verdict.py` (חדש)

לכל מנגנון, מ-`v9_shadow_events` **בסריקת-סלוט**:

```
K                = אירועים מתוקני-סלוט   ← לעולם לא N
t1_rate          = t1_before_stop על K
baseline         = שיעור-הפגיעה של הלייב באותו חלון
delta            = t1_rate − baseline
verdict:
   K < minimum(20/15/10)              → NOT_JUDGEABLE
   |delta| קטן ממרווח-הסמך על K       → NO_SIGNAL
   delta > 0 מובהק                    → CANDIDATE_PROMOTE
   delta < 0 מובהק                    → CANDIDATE_DISABLE
```

**‏🔴 שלוש דרישות שקובעות אם זה כלי או צעצוע:**
1. **`NOT_JUDGEABLE` הוא פלט לגיטימי ושכיח.** מנגנון שאין עליו מספיק —
   אומרים זאת. **אסור לתת אחוז על `n` חד-ספרתי.**
2. **מרווח-סמך, לא רק ממוצע.** ‏`7/10` ו-`70/100` אינם אותה טענה.
3. **המספרים חייבים לעקוף את שלוש מלכודות-היום** (למטה).
