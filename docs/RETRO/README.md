# MEMS26 Retrospectives

## Cadence
One retro per prompt, written immediately after UAT passes.
CC fills the retro using `docs/RETRO/template.md`.

## Files
- `template.md` — 5-question template (copy per prompt)
- `prompt_N.md` — filled retro for each prompt

## Purpose
Capture what worked, what broke, and what to change BEFORE
starting the next prompt. Prevents repeating the same mistakes
(see Anti-Patterns Log for the patterns themselves).
