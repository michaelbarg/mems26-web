## משימה
להדליק את 5 הדגלים בתצורת ה-SHADOW הרצה, עם מעקב והחזרה מבוקרת.

```
S2_ATR_RELATIVE=True
S3_RELATIVE=True
S1_CVD_OPENING=True
S1_IB_WIDTH_ATR=True
S1_DAYTYPE_STAGING=True
```

### צעדים
1. **אתר** היכן הדגלים נקראים (`os.environ` / `app.py:94` ודומיו) ומהי תצורת
   ה-ENV הקנונית ל-SHADOW (`scripts/start_all.sh` / `.env` / LaunchAgent). הדבק מה מצאת.
2. **הגדר** את 5 הדגלים ל-`True` ב-ENV הזה (לא בקוד — ב-config/env). תעד איפה.
3. **אמת זמינות ATR בזמן ריצה:** הדגלים היחסיים משפיעים רק כש-ATR זמין (≥period
   ברים). ודא ש-`atr_5min`/`atr_daily` מחזירים ערך אחרי warmup; אם `None` → המערכת
   נופלת לסף המוחלט (כלומר דגל דלוק בלי ATR = אפס שינוי). דווח אם ATR לא זמין.
4. **הפעל מחדש את SHADOW** (רק SHADOW) וודא עליה נקייה (אין crashes, health<100ms).

## מעקב (חובה — לא "הדלקנו ושכחנו")
תעד baseline של ~יום/סשן והשווה מול הקבוע:
- **קצב ירי** לכל מערכת (S2/S3/S4) — לפני מול אחרי. דגל את חריגות (0 fires או runaway).
- **התפלגות day_type** + opening_type — האם הגיונית (לא קורסת לסוג אחד).
- **`S1_CVD_OPENING` = shadow-scoring בלבד** — מחשב label חדש לצד הישן ורושם להשוואה;
  הסיווג החי נשאר המקורי. רק לאסוף את ההשוואה (PE/divergence) ל-EOD truth.
- אפס errors/warnings חדשים בלוגים.

## קריטריון החזרה (per-flag, מיידי)
אם דגל גורם להתנהגות מנוונת — **כבה אותו בלבד** (`=False`) ודווח, אל תכבה את כולם:
- ירי מנוון (0 או runaway) במערכת שמושפעת מהדגל.
- התפלגות day_type/opening קורסת לערך יחיד.
- errors/crashes שמתחילים אחרי ההדלקה.
ההחזרה היא שינוי env + restart — מיידית והפיכה, אפס סיכון (SHADOW).
