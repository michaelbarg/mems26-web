### A1 · `phantom_reconcile` לא משחרר סלוט — **הלייב נחסם 3.5 שעות היום**

`sierra_position_reconciler.py` — שחרור-הסלוט יושב **בתוך** `if _cancel_detect:`

```python
if _cancel_detect:              # ← manual_cancel בלבד
    ...
    _gw.on_trade_close({...})   # ← השחרור
```

**ראיה:** ‏#877 נסגרה 17:00 `reason=phantom_reconcile`; ‏`live_slot=877` נשאר תפוס עד
הריסטארט ב-21:07 (`diagnose` ⇒ `{'trade_id':'877','state':'PENDING'}`). סיירה
`position_qty=0`, אפס עסקאות פתוחות.

**⚠️ היקף — מתוקן 21:40 אחרי פילוח-לוג. אל תגזימו כמו שאני הגזמתי:**
```
13 "slot occupied" היום · 5 מאז 18:09 — כולן "skipping system 4 setup"
0  live_slot_occupied בפילוח-הגייטוויי  (הוא בשדה live_blocked_by, אחרי השער)
293 awaiting_release ← 97% מהחסימות. שער-תקין, שכבה אחת לפני הסלוט
```
⇒ הסלוט הפיל **5 מועמדי-S4**, לא את היום. ו**היום הוא חסך:** ‏ZLR — בדיוק המשפחה
שנחסמה — עשתה **-$390** על 7 סגורות-צל.

**⇒ הבאג אמיתי; הנזק היום לא. הערך הוא במניעת היום שבו המשפחה החסומה כן מרוויחה —
ולכן A2 (האזעקה) קודם ל-A1.**

**‏🔴 פעם שלישית לאותה מחלקה:** הקוד עצמו מתעד תקרית 08.07 (`trades.py`: *"exit closed
trade 310 but the gateway live_slot stayed occupied → ALL new fires blocked until
restart"*) ותיקון-חלקי 18.08 (bare-int נבלע) — **שהונח בתוך אותו `if`.**

**התיקון:** להוציא את בלוק-השחרור מה-`if _cancel_detect`. השומר ב-`on_trade_close`
(T-43c — משחרר רק כש-`position_qty==0` ואפס הזמנות מגִנות) נותן את הבטיחות.
**טסט חובה:** `phantom_reconcile` על עסקה חיה + סיירה שטוחה ⇒ `live_slot is None`.
הטסט חייב **להיכשל** אם מחזירים את הבלוק פנימה.

### A2 · אזעקת סלוט-תקוע — **חסרה לגמרי**

סלוט תקוע 4 שעות ואפס התראות — **גם כשהנזק היה אפס, אף אחד לא ידע.** **לבנות:** `live_slot` תפוס **> 15 דק'** בעוד

### A3 · `safe_execute` בולע כתיבות כושלות

`backend/v9/db/safe_writer.py:135` — החתימה היא `params: Union[Tuple, Sequence]`
(ממוקמים, `?`). מי שמעביר **dict** עם `:named` מקבל את **מפתחות ה-dict** כרצף:

```
[safe_writer] execute failed: A value is required for bind parameter 'q'
[parameters: [{0: 'q', 1: 'id'}]]
```

**וזה נבלע** (`Logs and returns 0 on failure`). ‏`t160_pnl_trust_audit.py --apply`
הדפיס **"Marked 62 trades"** ו-**אפס** נכתבו. הוא ספר כוונה ולא תוצאה.

**התיקון:** (א) לתמוך גם ב-dict+named, או **לזרוק** על סוג לא-נתמך — לא לבלוע.
(ב) **לספור כמה קוראים בייצור מעבירים dict ואינם בודקים החזרה.** זה כותב מרכזי.
(ג) כל קורא חייב לבדוק את הערך המוחזר.
