## LAYER 3: ENTRY EXECUTION (15-tick Reversal Bars!) 
 
 
### Primary Mechanism: 15-tick Reversal Bars 
Sierra Chart Type: reversal,15,0 
Each bar = 15-tick price reversal 
 
 
**Process:** 
1. Setup identified by Layer 1 (T1/T2/T3) 
2. Wait for matching 15-tick reversal bar 
3. Identify cluster in the bar (Volume Profile per bar) 
4. Entry = above cluster (LONG) / below cluster (SHORT) 
5. Stop = empty zone (low volume area) 
 
 
**Cluster Identification:** 
- Yellow POC of bar = primary cluster 
- 3 consecutive levels with most volume = secondary 
- Highest density of bid/ask volume 
 
 
**Empty Zone Identification:** 
- Levels below cluster with volume < threshold 
- Single print zones 
- Gap in footprint 
 
 
### Secondary: 12-tick Reversal Bars 
Used in specific conditions (TBD by Michael).

## Table: per_system_attempts 
 
 
```sql
CREATE TABLE per_system_attempts (
  id BIGSERIAL PRIMARY KEY,
  ts TIMESTAMP NOT NULL,
  system_id VARCHAR(20) NOT NULL,  -- T1_NUMBER_BAR, T2_WOODIES, T3_FOOTPRINT
  pattern_name VARCHAR(50),
  direction VARCHAR(5) NOT NULL,
  entry_price DECIMAL(10,2) NOT NULL,
  stop_price DECIMAL(10,2) NOT NULL,
  t1_price DECIMAL(10,2),
  t2_price DECIMAL(10,2),
  time_stop_minutes INT,
  confidence INT,
  
  -- Entry mechanism details
  entry_bar_type VARCHAR(20),        -- "reversal_15", "reversal_12"
  cluster_top DECIMAL(10,2),
  cluster_bottom DECIMAL(10,2),
  empty_zone_top DECIMAL(10,2),
  empty_zone_bottom DECIMAL(10,2),
  
  -- Context at firing
  market_state VARCHAR(20),
  chop_score INT,
  day_type VARCHAR(30),
  location VARCHAR(50),
  killzone VARCHAR(20),
  
  -- Multi-system context
  agreed_with_systems VARCHAR(100),
  conflicting_with_systems VARCHAR(100),
  
  -- Outcome (filled by worker)
  t1_hit BOOLEAN,
  t2_hit BOOLEAN,
  stopped_out BOOLEAN,
  close_reason VARCHAR(30),
  pnl_simulated DECIMAL(10,2),
  duration_minutes INT,
  mfe DECIMAL(10,2),
  mae DECIMAL(10,2),
  
  created_at TIMESTAMP DEFAULT NOW()
);


CREATE INDEX idx_per_system_ts ON per_system_attempts(ts);
CREATE INDEX idx_per_system_id ON per_system_attempts(system_id);
CREATE INDEX idx_per_system_outcome ON per_system_attempts(close_reason);
```

PART 11 — Anti-Patterns 
═══════════════════════════════════════════════════════════════════ 
 
 
## Technical (Sierra/DLL) 
- std::max/min are macros — use ternary 
- SCT_OSC_REJECTED doesn't exist — use SCT_OSC_ERROR 
- GetPersistentSCString (not GetPersistentString) 
- TPO subgraphs 1-indexed 
- Mac paths only 
- Re-add Study after each DLL build mandatory 
- Bridge restart after DLL changes mandatory 
 
 
## Logical 
- POC ≠ POC — always specify _VOL or _TPO 
- MFE bug (use close_reason/pnl) 
- Score 70+ broken (anti-correlation) 
- 90% LONG bias = Suffering Side violations 
- BE-on-C1 invites stop hunts 
- V3 day types don't match Zohar's 6 
- Day Type = playbook, not trigger 
 
 
## Architectural 
- All-conditions-must-pass = sequential gate trap 
- Score-based thresholds arbitrary 
- Belly=Direction wrong (must be measurement) 
- Snapshot volume wrong (must be cumulative) 
- 5-min not the only timeframe (15-tick reversal exists) 
- Wait-for-all-systems-to-agree = no entry ever
