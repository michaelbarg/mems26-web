# S1 — ניהול עסקה לפי סוג יום · 3 חוזים (ספק-אמת, Michael 2026-06-20)

**מקור:** Michael. זהו ה-spec הקובע ל**ניהול העסקה פר-סוג-יום**, הגשר שמחבר את זיהוי-סוג-היום (S1) לתבניות-הירי (S2/S4). כל היעדים **מבוססי-מבנה**, לא R:R קבוע.

## חלוקת 3 החוזים
חוזה לכל יעד (C1 / C2 / C3 = שליש כל אחד):
- **C1** — חוזה 1 = הורדת-סיכון + העברת סטופ ל-BE.
- **C2** — חוזה 2 = היעד העיקרי.
- **C3** — runner = trail (לא יעד קבוע).

**עיקרון-על:** יום **מאוזן → דהה** את הקצוות לכיוון POC · יום **כיווני → לך עם** התנועה.

## הגדרות
- `IB center` = (IBH + IBL) / 2.
- `הקרנה מדודה (measured move)` = רוחב ה-IB מוטל מנקודת-הפריצה.
- `תבנית שורט/לונג` = נר-היפוך 5-דק' בקצה (lower-high / דחייה / engulfing) **+ CVD divergence/absorption**. בלי האישור — אל תיכנס.
- `buffer סטופ` = 2–4 טיק מעבר לרמה המבנית (מעבר לזנב / ל-single-print), לא על הרמה עצמה.
- **R:R לפני כניסה:** אם המרחק ל-C1 קטן ממרחק-הסטופ → דלג או הקטן גודל. C1/C2 לעולם לא צמודים — ברמות-מבנה נפרדות.
- **trailing אחרי C2 (חובה):** ברגע ש-C2 נפגע, גלגל סטופ על C3 לפי מבנה 5-דק' (כיווני) או one-TF (טרנד). אל תשאיר את ה-runner על יעד סטטי.

## מיפוי לוגי (fade מול go-with)
- **דהה (mean-reversion):** Nontrend · Normal · Neutral → כניסה בקצה, יעד POC/קצה-נגדי.
- **לך עם (momentum):** Variation · Trend_DD · Trend_Normal → כניסה בכיוון הפריצה/המגמה, גלגל runner.

## הגשר למערכות היורות (S2/S4)
כל תבנית-ירי (S2: REACTIVE/INITIATIVE · S4: HFE/ZLR/TLB/…) צריכה להיכנס תחת **המשמעת של סוג-היום**:
- ב**ימי-דהה** — מותר רק לתבניות-fade בקצה (לעבר POC); תבניות-המשך נחסמות.
- ב**ימי-כיוון** — מותר רק לתבניות **עם-הכיוון**; fade נגד-המגמה נחסם; runner מגולגל.
- כל ירי מנוהל לפי C1/C2/C3 של סוג-היום (לא R:R קבוע).
